# Spec Delta

## MODIFIED Requirements

### Requirement: Quick add task
The phone SHALL offer a quick-add button on Home that opens the new task form (title, optional due date and assignment) as a full-screen sheet; saving a task with only a title SHALL be possible, and the keyboard's Enter key SHALL save it.

#### Scenario: Add by title
- **WHEN** the user taps the quick-add button, types "Call the bank" and presses Enter
- **THEN** the standalone task "Call the bank" is created and appears in To do
